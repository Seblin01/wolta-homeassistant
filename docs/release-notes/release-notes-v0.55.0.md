# v0.55.0 – Control system list from Wolta, in alphabetical order

- **The control system list comes from Wolta.** The setup step and the "Wolta needs your battery's control system" repair now show the list Wolta serves, so a control system added at Wolta can be picked without waiting for a new release of the integration. If Wolta cannot be reached, or an older Wolta server answers without English names, the list built into the integration is used, as before.
- **Four new control systems:** 1KOMMA5°, Custom-built (Home Assistant, script), Darkstar and Solis. They were the names owners most often typed under Other. Custom-built is for your own rules in Home Assistant or your own scripts; EMHASS and Darkstar keep their own entries.
- **The list is in alphabetical order**, with Other last.

You do not need to do anything. Your control system stays as it is.
