# v0.55.1 – categories for the Home Assistant Marketplace

Nothing changes in how the integration works. This release prepares Wolta for Home Assistant 2026.11, where HACS becomes part of Home Assistant as the Marketplace.

- **Wolta has categories in the manifest:** Energy › Solar & batteries and Energy › Energy prices. The Marketplace lists integrations by them.
- **About the missing icon in HACS:** the HACS store shows "icon not available" for Wolta. The HACS store fetches icons only from the brands repository, which no longer accepts custom integrations, so it never sees the icon Wolta ships. Home Assistant's own pages show it, and so does the Marketplace from 2026.11.

You do not need to do anything. Update when it suits you.
