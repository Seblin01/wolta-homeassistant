# v0.55.2 – clearer errors and sensor help

- **Refusals show Wolta's reason.** Before, some showed "check your internet connection" although the connection was fine. The reason is in Swedish. A real connection problem still shows the connection error.
- **Purchase date with stages.** The purchase date is the first stage's. The settings form now stops a later or cleared date before saving. Add later purchases as stages on wolta.se.
- **Sensor help.** Each energy sensor picker says what it wants: a kWh meter that only goes up, the same sensor as in the energy dashboard.
- **Where to change the sensors.** The Configure menu points to Reconfigure in the ⋮ menu.

You do not need to do anything.
